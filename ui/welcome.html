Benvenuto in Juggl

Tutte le tue sessioni di Claude Code in un posto solo. In cima trovi chi aspetta te.

Juggl lo usa quando parla di te alle sessioni.

Cosa serve

Juggl lavora con Claude Code, che deve essere già installato su questo Mac.

Collega Juggl a Claude Code

Per vedere le sessioni, Juggl aggiunge un piccolo collegamento (un hook) alle impostazioni di Claude Code.

Cosa succede
  • Prima faccio una copia di ~/.claude/settings.json.
  • Aggiungo il collegamento di Juggl. Gli hook che hai già restano come sono.
  • Lo togli quando vuoi da Impostazioni, Disinstalla collegamento.

Avvisi e microfono

Juggl chiede i permessi di macOS solo quando servono.

Notifiche

Ti avviso quando una sessione finisce o ti chiede qualcosa.

Microfono, se vuoi dettare

macOS te lo chiede la prima volta che premi il microfono nella casella. L'audio si trascrive sul Mac e poi si cancella.

Importa i tuoi progetti

Cerco le chat che hai già fatto con Claude Code e i progetti sul Mac. Resta tutto qui: niente esce dal Mac.

Ogni progetto scelto diventa una sessione pronta, con il contesto già preparato: parte quando le scrivi, prima non consuma niente. Le chat che hai già vanno in Archiviate.

Richieste

Ogni cosa che chiedi a una sessione diventa una richiesta. Juggl segue se è fatta, in lavoro o se serve te.

Quando una sessione chiede il tuo ok, rispondi con Ok, No o Rispondi senza aprire la chat.

⌘R apri le richieste

Le scorciatoie principali

Juggl, la chat fissata in cima, è il tuo assistente: smista le richieste alle sessioni giuste, apre quelle nuove e ti dice a che punto siete.

Le Impostazioni sono nel menu Juggl. Da lì puoi rivedere questo giro quando vuoi.
