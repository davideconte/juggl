# Contributing

Thanks for looking at Juggl.

- **Bugs and ideas:** open an Issue with the version, the operating system and the steps to reproduce.
- **Pull requests:** small fixes are welcome. For new features, open an Issue first so we can agree on the approach: review time is limited.
- **Before you open one:** run the checks listed under "Build from source" in the README. CI runs them on macOS and checks the build on Linux.
- **Code language:** code, comments and commit messages are in English. The visible text of the app is Italian for now: new visible strings go in the strings object at the top of each file, so they can be translated.
- **License:** by contributing you agree that your contribution is released under the same license as the project (FSL-1.1-ALv2, see LICENSE.md).
